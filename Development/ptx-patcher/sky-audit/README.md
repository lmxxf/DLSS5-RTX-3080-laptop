# 天空色带与转换实验

此目录保留按时间推进的脚本、失败结果、文本日志和回执。生产构建入口是上一级 `build_sm86_dlls.py`；旧诊断脚本是在不断变化的实现上运行的历史控制实验，不作为发行构建接口。

当前结论见 [去量化控制变量回执](去量化控制变量回执.md)。`quantmapped` 实验曾推翻“补回量化就足够”的判断；之后确认多定义 fallback 的误映射，并由只拒绝多定义、不加量化的版本消除条纹和恢复速度。

GPU 转换有限值检查、MMA 坐标检查和性能/图像检查是不同证据。模型输出 PNG、RGB32 浮点转储和大体积底层 trace 保留在本机/发布验证记录，不随源码提交；回执中的这些文件名是本地实验产物。
