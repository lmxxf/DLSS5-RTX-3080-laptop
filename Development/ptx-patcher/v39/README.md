本轮无晋升，保留V3.8为唯一1.00×，分支5为Open1/3。

## 参考与验收

- 本轮唯一分母与输出参考：V3.8，SHA `da27f34c5e10b884dd02b448eab424a4f44109ef08efc83e6a447100acd697c3`。由源配方重新构建baseline得到同SHA，原15槽位O4及Host/权重/参数ABI保持不变。
- 运行计数 {'smoke': 24, 'timed': 168, 'repeat': 24}；精确（含基线）174次所测末帧0bit，近似/实证42次按预设PSNR≥50dB、maxabs≤1/64、nonfinite0和720p天空变号0验收。
- 正式计时严格串行50 warmup / 80 iter，正向ABBA、反向BAAB；首轮三档六方向全胜均补repeat，所有数据均相对V3.8，不借V3.1历史收益记功。

## 构造与审计

- 零折叠：fb1456/fb3456/no_fb0up总覆盖分别540/540/676位点，增量为40/40/176。计划原FB00/01及排除计数与既有审计不符，按实际60/40与单入口4处纠正，证据input-audit-corrections.json；候选范围保持原指令。每个正零由独立mov/cvt定义链复核，no_fb0up排除FB00 upsample；38活跃入口的REG、STACK均未比V3.8增加。精确候选对比V3.8逐位验收。
- Pack4：在V3.8原500处FB456零折叠上，分别叠加FB03/06、FB02/03/05/06经验Pack4；未增加全网零折叠。质量门与实证标签保持不变，不从所测输出一致推断任意输入的中间激活有界。
- UP定义链：全部4744处独立转换来自2372个32位拆半字；实际2682处满足同基本块、无守卫且源32位未覆写，删除1341个无其他用户的拆分。其余跨块位点保留原解码：名称all表示对全网符合条件者应用，不声称2372对全部改写。逐点表up-pair-audit.json与计数up-pair-summary.json。
- UP低/高半分别直接使用0x9180/0xb3a2，避免高半右移。GPU原语用全65536半字模式×256对侧污染、旋转两遍，共33554432个32位词（67108864个half2输出）对V3.8旧独立UP解码零差异，含7f/ff保留码；不改写为Ada原生NaN语义。6项安全性测试覆盖覆写、源/目标别名、守卫、跨块与其他用户保留拆分。
- UP精选：计时前从up_pair_all实际资源表选择REG/STACK/STL/LDL不增加且官方CTA/SM不下降的34个活跃入口；未剖析与未选入口保留基线，重编译后再次核验。其余模块与排除入口的代码一致性见isolation-validation.json。
