Magpie DLSS5 RTX30 0.1.0 - native PTX release

Default: native Feature 18 NR (preset 2/style 1) -> native NVIDIA DLSS SR.
No ReShade, CUDA add-on or external DLSS5-AMD weights are required. Do not mix old package files back in.
Magpie.exe has a hash-guarded minimal patch fixing its hard-coded NR preset to 2; see preset2-patch.json. Automatic updates are disabled.
The NR DLL is the validated 15/15 O4 Ampere build. 720p NR GPU time was about 16 ms; this is not a guarantee of whole-game FPS.
Use Magpie's own comparison controls; the old add-on F6 toggle is gone. See README.txt for timing limits and rollback notes.
