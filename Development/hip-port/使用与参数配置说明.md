## 一、三个压缩包怎么选？装在哪里？

每个版本的网盘里都有三个完整的 `.zip` 包，它们的底层 HIP 算子（每架构 40 个模块，共 80 个）和神经网络权重完全相同，区别只在于**怎么把画面截获下来喂给网络**：

| 压缩包名称 | 适用游戏 | 安装位置与使用方式 |
|---|---|---|
| **`OptiScaler-DLSS5-AMD-0.44.zip`**（常规包） | 原生支持 DLSS 的常规 DX12 游戏（如《剑星》《匹诺曹的谎言》《赛博朋克 2077》） | 解压到**游戏真正的可执行文件（`.exe`）同级目录**（注意不是外层 Launcher 目录，例如《剑星》是 `StellarBlade\SB\Binaries\Win64\`）。OptiScaler 接管游戏 DLSS 并用 FSR 放大，我们的 `dlss5-amd.addon64` 在 FSR 超分之前先跑 DLSS5 网络 |
| **`Magpie-DLSS5-AMD-0.44.zip`**（便携窗口缩放包） | 任意 DX11/DX12/Vulkan 游戏，不要求游戏支持 DLSS/FSR | 解压到任意独立文件夹直接运行 `Magpie.exe`。游戏设窗口或无边框窗口，按 `Alt+Shift+A` 缩放（包内预设效果组第一项 `FSR3_SR` 就是 DLSS5 入口，后面跟 FSR4 放大和可选 XeSS 帧生成） |
| **`OptiScaler-REFramework-DLSS5-AMD-0.44.zip`**（RE9 / 鬼武者专用包） | 《生化危机 9》《鬼武者：剑之道》等常规钩子切不开命令列表的特殊游戏 | 解压到游戏 `.exe` 同级目录。采用专用 OptiScaler 宿主 + `LmxxfNrRuntime.dll` 成对工作（**切勿与常规包混装**） |

> **⚠️ 微软商店 / Xbox Game Pass 游戏（如《鬼武者》）特别说明**：
> Xbox 虚拟挂载盘（`C:\Program Files\WindowsApps\...`）是系统只读的。`0.44` 起，`LmxxfNrRuntime.dll` 会**优先读取并写入可写的镜像目录 `C:\XboxGames\<游戏名>\Content\DLSS5-AMD\`**（例如 `C:\XboxGames\Onimusha- Way of the Sword\Content\DLSS5-AMD\custom-config.txt`），并且按 `F9` 时会先在内存里立即切换生效，哪怕磁盘只读也绝不会失效或回滚。

## 二、改哪个配置文件？（三层配置规则）

在 `DLSS5-AMD\` 文件夹下有三个配置文件层级，程序按**从低到高**的顺序读取并合并：

```text
1. default-config.txt（随包默认模板）
   ↓ 被覆盖
2. custom-config.txt（你自己的配置，升级绝不覆盖 ★只改这个文件★）
   ↓ 被覆盖
3. native-game-flags.txt（0.40 以前的老版单文件，如果老目录里还留着就会盖过 custom）
   ↓ 被覆盖
4. Windows 系统环境变量 DLSS5_*（最高优先级）
```

### 核心规矩（防踩坑必看）

1. **永远只改 `DLSS5-AMD\custom-config.txt`**：
   - 包里自带一份 `custom-config.template.txt`（首次安装会自动生成空白的 `custom-config.txt`）。
   - **不要动 `default-config.txt`**（下次升级新包会被覆盖掉）。
   - **不要把整个 `default-config.txt` 全选复制进 `custom-config.txt`**！你只需要改哪一项，就在 `custom-config.txt` 里写哪一行（例如只写一行 `DLSS5_STRENGTH=0.7,0.3`），没写的项会自动沿用新版本的默认最佳值。
2. **老用户升级如果发现“改了 `custom-config.txt` 没反应”**：
   - 八成是游戏目录的 `DLSS5-AMD\` 里还留着 0.40 以前的 **`native-game-flags.txt`**，或者你的 `custom-config.txt` 里以前按过 `F9` 留下了 `DLSS5_MULTI_PASS=1`。
   - 解决办法：直接删掉老的 `native-game-flags.txt`，并检查 `custom-config.txt` 里有没有旧的同名行。
3. **写法格式**：
   - 一行一个 `DLSS5_参数名=值`，`#` 开头的行是注释。
   - 同一个文件里如果同一个参数写了两次，**以最后一行（最下面那行）为准**。
   - 等号后面留空（例如 `DLSS5_SKIP_BLOCKS=`）代表强制清空、恢复程序内置默认。

## 三、游戏内快捷键速查表（无需切出桌面）

在游戏运行过程中可以直接按键（常规 OptiScaler 包、Magpie 包均支持；`0.44` 起《鬼武者》/ RE9 专用包也支持 `F9` 实时切换）：

| 按键 | 功能 | 详细说明 |
|---|---|---|
| **`F6`** | **开关 DLSS5 网络** | 按一下立刻旁路神经网络（只剩原版超分），再按一下恢复。用来原位对比开/关 DLSS5 的画面差异（仅常规包/Magpie 包） |
| **`F7`** | **开关左上角状态/FPS 字条** | 隐藏或显示屏幕左上角的 `DLSS5 ON ...` 黄字提示与帧率显示，不影响网络计算 |
| **`F8`** | **切换 `AE` / `EXACT` 模式** | 在开启 ViT 自适应复用时，实时切换 `AE`（画面变化小时复用 ViT 省算力）与 `EXACT`（每帧完整重算 ViT） |
| **`F9`** | **循环切换模型与叠层遍数** | 按 **`0.5x → 1x → 2x → 3x → 0.5x`** 顺序循环切换！<br>• **`0.5x`**（0.44 默认）：`310.9.16.0` 新增的 **31 块 Small 轻量模型**，速度比 1x 快约 **33%～39%**<br>• **`1x`**：原版 **71 块完整模型**跑 1 遍<br>• **`2x`**：原版 71 块模型连跑 2 遍（风格更浓，耗时翻倍）<br>• **`3x`**：原版 71 块模型跑 3 遍（默认跑 2 遍真实网络 + 预测第 3 遍）<br>按下后内存立即切换，并自动把 `DLSS5_MULTI_PASS=...` 写进 `custom-config.txt` |

## 四、全部常用参数详解（写进 `custom-config.txt`）

下面把所有实用参数按功能分成 6 组，标明了**默认值、可选值、画面/速度效果、以及改完要不要重启游戏**。

### 1. 模型选择与多遍叠层（控制“用哪个模型、跑几遍”）

| 参数名 | 0.44 默认值 | 可选值 | 效果说明与性能代价 | 是否热重载 |
|---|---|---|---|---|
| **`DLSS5_MULTI_PASS`** | **`0.5`** | `0.5` / `1` / `2` / `3` | • **`0.5`**（默认）：启用 NVIDIA `310.9.16.0` 新增的 **31 块 Small 模型**。RX 9070 XT 单帧耗时：1080 档 **`5.55 ms`**（比 1x 快 39%）、900 档 **`4.38 ms`**（比 1x 快 33%），权重显存减半。<br>• **`1`**：启用原版 **71 块大模型**单遍（1080 档 **`9.12 ms`**、900 档 **`6.54 ms`**）。<br>• **`2` / `3`**：71 块大模型每帧叠层连跑 2 遍或 3 遍，上一遍的输出当下一遍的输入，光影风格逐遍加重，耗时约 N 倍。 | **是**（按 `F9` 或改文件 1 秒内生效；1080 档 `0.5x ↔ 1x` 零 IO 原地切换） |
| **`DLSS5_MULTI_PASS_PREDICT`** | **`1`** | `1` / `0` | **第三遍快速预测**（仅在 `DLSS5_MULTI_PASS=3` 时生效）：<br>• **`1`**（默认）：真跑前 2 遍网络，第 3 遍用原输入与前两遍残差在局部直接外推预测，省掉约 1/3 耗时（有损近似）。<br>• **`0`**：老老实实真跑完整 3 遍网络。 | 常规包**是**；RE9 需重启 |
| **`DLSS5_MULTI_PASS_SKIN_PROTECT`** | **`0`** | `0` / `1` | **多遍肤色保护**（仅在 `DLSS5_MULTI_PASS=2` 或 `3` 时生效）：<br>• **`1`**：用肤色启发式掩码保护人物皮肤——皮肤区域保留第 1 遍的自然质感，背景/盔甲/场景使用第 2/3 遍的浓烈增强，防止叠层后人脸太油或过锐。<br>• **`0`**（默认）：全画面统一使用最后一遍输出。 | 常规包**是**；RE9 需重启 |
| **`DLSS5_MULTI_PASS_SKIP_BLOCKS`** | 空值 | 空值，或块号列表（如 `42,43,46` 或 `31,32,33,34,35,36,37,38,40,41,42,43,44,45,46,47`） | **叠层减负**：只在第 2、3 遍跳过指定的块，第 1 遍永远跑完整网络。长列表（跳过第 2/3 遍的 ViT + C512 上行段）可让 3 遍耗时降低约 13%～14%，但后几遍加上的对比度也会减弱。 | 否（需重启） |
| **`DLSS5_MULTI_PASS_HOTKEY`** | **`F9`** | `F1`～`F24`、键码（如 `0x78`）、`0`（关闭） | 自定义游戏内循环切换 `0.5 → 1 → 2 → 3 → 0.5` 的快捷键。写 `0` 禁用快捷键。 | 否（需重启） |

### 2. 画面强度与风格控制（觉得“太油腻 / 太锐 / 偏色”调这里）

| 参数名 | 0.44 默认值 | 可选值 | 效果说明 | 是否热重载 |
|---|---|---|---|---|
| **`DLSS5_STRENGTH`** | **`auto`** | `auto`，或两个用逗号隔开的数字 `亮度强度,色彩强度`（常规包范围 `0.0～3.0`，RE9 范围 `0.0～1.0`） | **最常用的观感微调项！** 必须写两个数 `a,b`：<br>• **第一个数 `a`（亮度/光影细节转移）**：控制高光立体感、材质纹理和高频细节增强。<br>• **第二个数 `b`（色彩混合强度）**：控制神经网络对画面色调/饱和度的改变。<br>• **`auto`**（默认）：《赛博朋克 2077》自动用 `1,0`（只转亮度细节、完全保留游戏原版霓虹色彩，防止在游戏 LUT 前改色相把绿光变褐），其余所有游戏自动用 `1,1`（满血增强）。<br>• **调校建议**：觉得默认颜色太浓/偏色但喜欢立体感 → 写 `DLSS5_STRENGTH=1.0,0.3` 或 `1,0`；觉得整体风格太冲想温和一点 → 写 `DLSS5_STRENGTH=0.7,0.3`。*(注意：写 `0,0` 只是不显示增强结果，网络仍在后台空跑，想停掉计算请按 `F6`)* | **是**（改完保存，游戏里 1 秒内直接看到变化！） |
| **`DLSS5_STYLE`** | **`1`** | `0` / `1` / `2` | **NVIDIA NGX 内置风格档位**（注入网络入口的第 6 通道特征）：<br>• **`1`**（默认）：原版 DLL 在《剑星》里捕获到的默认风格。<br>• **`0`**：NVIDIA 离线参考输出风格。<br>• **`2`**：第三种内置风格预设。 | 否（需重启） |

### 3. 时域稳定与单遍残差增强（控制“高光抗闪烁”与“单遍强化”）

> **适用范围**：常规 OptiScaler 包与 RE9 /《鬼武者》专用包（Magpie 包不启用此组时序消费者）。

| 参数名 | 0.44 默认值 | 可选值 | 效果说明 | 是否热重载 |
|---|---|---|---|---|
| **`DLSS5_TEMPORAL_MODE`** | **`0`**（《鬼武者》安装配置为 `1`） | `0` / `1` / `2` / `3` | **统一时序模式主开关**：<br>• **`0`**（默认）：关闭附加时序滤波，每帧纯粹输出当前神经网络画面，无拖影风险，无额外开销。<br>• **`1`**（**Fast History**）：TheAutomatic 模型门控历史混合——利用模型第 70 块的 `post70-history-head.f16`（及 `0.5x` Small 模型的专用 history head 与 `0x3A23` 混合系数）把上一帧输出混合并回灌给下一帧网络输入，抑制帧间闪烁。支持 `0.5x` 和 `1x`（切到 `2x/3x` 时自动暂挂，切回 `0.5x/1x` 自动恢复）。<br>• **`2`**（**低频时域稳定**）：在编解码器颜色域内把网络修正量拆成低频与高频，**只对低频光影做约 80ms 的跨帧平滑**，高频纹理完全保留当前帧，不回灌网络。<br>• **`3`**（**单遍低高频残差增强**）：只跑 1 遍网络，在保持低频时域稳定的同时，直接把低频修正放大约 `1.5×`、高频细节修正放大约 `2.0×`（带高光防溢出软压缩），用单遍算力做出更浓烈的立体反差感。 | 否（修改 `TEMPORAL_MODE` 需重启游戏；但在 `MODE=1` 下按 `F9` 切 `0.5x ↔ 1x` 可实时无缝切换各自的历史头） |
| **`DLSS5_TEMPORAL_ENHANCE_STRENGTH`** | **`1`** | `0.0 ～ 2.0` | **仅在 `DLSS5_TEMPORAL_MODE=3` 时生效**：控制单遍残差额外放大的倍数。<br>• `1` 为标准增强（低频 `1.5×`、高频 `2.0×`）；觉得太浓或暗部反差太大可改 `0.5`；`2` 为最强；`0` 则退回原始单遍输出。 | 否（需重启） |
| **`DLSS5_TEMPORAL_MV_UNJITTERED`** | 未设置（静态回退） | `1` / `0` | 仅在 `DLSS5_TEMPORAL_MODE=1` 或 `2` 且确认宿主提供了未抖动、与渲染尺寸 1:1 匹配的运动向量（Motion Vectors）时设为 `1`；拿不准请勿开启（默认使用安全的屏幕空间颜色门控回退）。 | 否（需重启） |
| **`DLSS5_FAST_HISTORY_DEPTH_INVERTED`** | 未设置 | `0` / `1` | 仅在开启上面运动补偿时声明游戏深度缓冲方向：`0` = 常规深度，`1` = 反向深度（Reversed-Z，现代虚幻 4/5 游戏常用）。不猜默认值。 | 否（需重启） |

### 4. 网络计算档位与几何分辨率（画质清晰度 vs 显存/帧率）

首先分清两个概念：**游戏渲染分辨率**（比如 2K 质量档是 `1707×961`）和 **DLSS5 网络内部计算档位**（`720` / `900` / `1080`）。

| 参数名 | 0.44 默认值 | 可选值 | 效果说明与性能代价 | 是否热重载 |
|---|---|---|---|---|
| **`DLSS5_NETWORK_HEIGHT`** | **`auto`** | `auto` / `720` / `900` / `1080` | **网络计算档位选择**：<br>• **`auto`**（默认推荐）：只要输入宽高都不超过某档位的 `110%`，就自动缩进该档位计算——`≤1408×792` 走 **720 档**，`≤1760×990` 走 **900 档**（所以 **2K 质量档 `1707×961` 默认自动走 900 档**，单帧仅 `4.38 ms`！），其余走 **1080 档**。<br>• **强制写 `900`**：哪怕游戏是原生 1080p 或 2K DLAA，也强行压到 900 档算，单帧从 `5.55 ms` 降到 `4.38 ms`（`1x` 从 `9.12 ms` 降到 `6.54 ms`），适合帧率吃紧时白嫖速度。<br>• **强制写 `1080`**：让 2K 质量档（`1707×961`）也升档到 `1920×1152` 网格算，画面最锐但耗时增加约 27%。 | 否（需重启） |
| **`DLSS5_NETWORK_FREE_RES`** | **`0`** | `0` / `1` | **原生任意分辨率模式（不吸附固定档位）**：<br>• **`0`**（默认）：使用上面高效的 `720/900/1080` 固定档位。<br>• **`1`**：不缩放进固定档，游戏渲染是多少分辨率（最高支持到 4K `3840×2176`），网络就按 64 对齐补边后原尺寸硬算！在 2K Native AA / 4K 下对 NVIDIA 原版的还原度最高（1440p PSNR 从 35.9 升至 46.4 dB），但耗时随像素量暴涨（1440p 耗时是 1080 档的 `1.7×`，4K 是 `3.6×`）。 | 否（需重启） |
| **`DLSS5_NETWORK_1080_ROWS`** | **`1152`** | `1152` / `1088` | **1080 档的垂直处理行数**（仅对 `1x/2x/3x` 的 1080 档生效）：<br>• **`1152`**（默认）：NVIDIA 原版几何合同（1080 行画面 + 72 行镜像补边）。<br>• **`1088`**：紧凑几何（只补 8 行），少算 5.6%，1080 档每帧快约 `0.45 ms`，但对原版掉约 1.6 dB。 | 否（需重启） |
| **`DLSS5_FIT_LARGE`** | **`1`** | `1` / `0` | 当输入分辨率超过 `1920×1080`（如 2K DLAA `2560×1440`）且未开 `FREE_RES` 时：`1`（默认）会自动缩到 1080 档跑网络再按原分辨率合成输出；`0` 则拒绝接管超 1080p 输入。保持 `1` 即可。 | 否（需重启） |

### 5. 算子速度与精度取舍开关（有损加速 vs 逐位精确）

| 参数名 | 0.44 默认值 | 可选值 | 效果说明与性能代价 | 是否热重载 |
|---|---|---|---|---|
| **`DLSS5_VIT_ADAPTIVE`** | 常规包 **`1`** / Magpie与RE9 **`0`** | `1` / `0` | **ViT 自适应跨帧复用（状态行显示 `AE`）**：<br>• **`1`**：当前后帧画面变化低于阈值时，直接复用上一帧算好的 8 层全局 ViT 特征（最多沿用 `DLSS5_VIT_REUSE_PERIOD=4` 帧，且近似帧绝不递归回写），静止画面快 **9%～11%**，运动画面快 **5%～6%**。`0.5x` Small 模型与 `1x` 71 块模型均支持。<br>• **`0`**：每帧强制完整重算 ViT（状态行显示 `EXACT`）。游戏里随时按 **`F8`** 可实时切换对比。 | 按 **`F8`** 实时切换；改配置文件需重启 |
| **`DLSS5_FAST_NUMERIC`** | **`1`** | `1` / `0` | **快速数值路径**：<br>• **`1`**（默认）：C32/C64/C128/ViT/C512 算子内部省去冗余的 FP16 半精度往返舍入、Softmax 分母直接用硬件 `rcp`，每帧快约 `0.1 ms`，对 NVIDIA 原版 PSNR 基本不变（`47.55 dB`）。<br>• **`0`**：严格执行每一步半精度舍入（参考数值路径）。 | 否（需重启） |
| **`DLSS5_SKIP_BLOCKS`** | 空值（不跳块） | 空值，或 `42,43,46` | **单遍跳块加速**（仅对 `1x` 71 块模型生效）：<br>• **空值**（默认）：跑满全部块，无偏色。<br>• **`42,43,46`**：跳过 ViT 段的第 42、43、46 三块，900/1080 档每帧快约 `0.20 / 0.32 ms`，但会掉约 `3.3 dB` 并有轻微整体色调偏移。现在已有快得多的 `0.5x` Small 模型，一般不再需要靠跳块凑帧率。 | 否（需重启） |

### 6. 游戏兼容性、接入路线与屏幕提示开关

| 参数名 | 0.44 默认值 | 可选值 | 效果说明 | 是否热重载 |
|---|---|---|---|---|
| **`DLSS5_PRE_UPSCALE`** | 常规包 **`auto`** / Magpie **`0`** | `auto` / `1` / `0` | **前置 vs 后置超分路线**（仅常规 OptiScaler 包）：<br>• **`auto`**（默认）：首帧自动探测游戏的命令列表结构。像《剑星》《匹诺曹的谎言》《2077》走 **`1`（前置路线：低分辨率渲染图 → DLSS5 → FSR 放大）**，画质最好且算力最省；遇到《极限竞速：地平线 6》《卧龙 2》这种在同一条命令列表里超分后还继续绘制画面的游戏，首帧探测到不安全会**自动切回 `0`（后置路线：FSR 放大后 → DLSS5）**，不再出现“装了没效果”。<br>• 如果想强制走后置路线，可写 `DLSS5_PRE_UPSCALE=0`。 | 否（需重启） |
| **`DLSS5_PRE_UPSCALE_ASYNC`** | **`auto`** | `auto` / `1` / `0` | 前置路线的队列提交方式：`auto` 对绝大多数游戏走 `1`（异步提交），对《赛博朋克 2077》自动走 `0`（同步提交，防止 REDengine 瞬态复用的颜色缓冲被覆盖成天空盒）。 | 否（需重启） |
| **`DLSS5_UPSCALER`** | **`ffx`** | `ffx` / `xess` | 常规包挂接的超分后端：默认 `ffx`（FSR）；如果游戏在 OptiScaler 里选的是 XeSS 路线（如《浪人崛起》），改为 `xess`。 | 否（需重启） |
| **`DLSS5_SHOW_FPS`** | **`1`** | `1` / `0` | 是否在屏幕左上角显示黄色帧率与档位文字（也可在游戏里直接按 **`F7`** 开关）。 | **是**（1 秒内生效，或按 `F7`） |
| **`DLSS5_NOTICE`** | **`1`** | `1` / `0` | 是否在左上角显示初始化（`INITIALIZING...`）或分辨率不支持等状态提示。 | **是**（1 秒内生效） |
| **`DLSS5_FRAME_STATS`** | **`0`** | `0` 或秒数（如 `5`） | 性能诊断日志：设为正整数 `N` 时，每 `N` 秒往 `DLSS5-AMD\logs\frame-stats.txt` 追加一行统计（帧率、帧间隔 avg/p50/p99/max、1% low）。日常玩保持 `0` 零开销。 | 否（需重启） |

## 五、直接抄作业：5 套常用 `custom-config.txt` 配方

选一套适合你的，直接覆盖粘贴进 `DLSS5-AMD\custom-config.txt` 即可（不要把多套叠在一起贴）：

### 配方 1：0.44 默认甜点档（速度最快、日常主力）
> 其实不用写任何东西（清空 `custom-config.txt` 就是这套），列出来供老用户洗掉旧配置：
```ini
DLSS5_MULTI_PASS=0.5
DLSS5_TEMPORAL_MODE=0
DLSS5_STRENGTH=auto
```

### 配方 2：觉得默认画面有点浓/油，想要温和自然的增强感
> 保留 `0.5x` 的高帧率，把亮度细节收到 `0.7`、色彩改动压到 `0.3`（保存后游戏里 1 秒直接生效）：
```ini
DLSS5_MULTI_PASS=0.5
DLSS5_STRENGTH=0.7,0.3
```

### 配方 3：原汁原味 71 块满血单遍（显卡帧率富余、追求原版大模型质感）
> 锁死 60 帧绰绰有余时，用原版 71 块大模型单遍：
```ini
DLSS5_MULTI_PASS=1
DLSS5_TEMPORAL_MODE=0
DLSS5_STRENGTH=1,1
```

### 配方 4：抗高光闪烁稳态档（适合金属/水面高光闪烁明显的游戏）
> 开启 `MODE=1` 模型门控时域混合（`0.5x` 和 `1x` 都能用，游戏里还能按 `F9` 切）：
```ini
DLSS5_MULTI_PASS=0.5
DLSS5_TEMPORAL_MODE=1
```
*(若在部分游戏里觉得 `MODE=1` 转镜头有轻微拖影，可把 `DLSS5_TEMPORAL_MODE=1` 改成 `DLSS5_TEMPORAL_MODE=2`，只平滑低频光影、高频完全不拖影。)*

### 配方 5：浓烈画风 / 截图党（2 遍叠层 + 人脸肤色保护）
> 跑 2 遍网络把立体光影拉满，同时开启肤色保护防止主角脸部过油：
```ini
DLSS5_MULTI_PASS=2
DLSS5_MULTI_PASS_SKIN_PROTECT=1
DLSS5_TEMPORAL_MODE=0
```

## 六、常见问题排查（FAQ）

1. **为什么我升级到 0.44 后，进游戏还是 `1x` 而不是默认的 `0.5x`？**
   - 因为升级不会覆盖你原有的 `custom-config.txt` 或老版 `native-game-flags.txt`。如果以前按过 `F9`，文件里已经写死了 `DLSS5_MULTI_PASS=1`。在游戏里按一下 `F9` 切到 `0.5x`，或者打开 `custom-config.txt` 删掉 `DLSS5_MULTI_PASS=1` 那行即可。
2. **为什么《剑星》开了 `0.5x` 还是显示 60 帧？**
   - 游戏开了垂直同步或 60 帧上限，在 `1x`（`9.12 ms/帧`）时就已经跑满 60 帧了，切到 `0.5x`（`5.55 ms/帧`）主要体现为显卡功耗/温度大幅下降、4K 或高画质下不再掉帧，或者解开游戏帧率上限后帧率暴涨。
3. **为什么《鬼武者》退出游戏后显卡风扇还在转 / 显存还占着 7GB？**
   - 《鬼武者》游戏本体有退出不杀后台进程的 Bug（无窗口 `OnimushaWotS.exe` 残留）。退出游戏后如果要在目录里替换文件或跑测试，去任务管理器把 `OnimushaWotS.exe` 结束掉即可。
4. **更多底层实现与全量开关字典在哪看？**
   - 开发者级逐项配置字典：[`scripts/CONFIGURATION.zh-CN.md`](scripts/CONFIGURATION.zh-CN.md)
   - 默认完整带注释模板：[`scripts/hip-game-flags.txt`](scripts/hip-game-flags.txt)
   - 历次版本更新记录：[`CHANGELOG.zh-CN.md`](CHANGELOG.zh-CN.md)
