# PTX V2.9 Unified Mul Pack 实验

结论：保留V2.7严格默认。修正后的A原语及整网0bit，但两轮收益方向不稳定；B三档有收益，保留为明确非0bit的实验DLL，未覆盖生产或发布包。

## 先修正用户给定算法的一个操作数顺序错误

原式 `lop3 y,y,source,0x7f007f00,0xd8` 在掩码位选择source幅值，原语大面积不符（每种排列16,774,912/16,777,216对）。正确顺序为 `lop3 y,source,y,0x7f007f00,0xd8`，保留量化幅值和原符号。代码中两候选均使用修正式，原始失败留在primitives-original.json。

## 原语与资源

全部65536种half位型分别置于两个通道，另一通道遍历256种poison，共33,554,432对/候选，包含NaN/Inf和正负零。A全部0 mismatch；B每种排列10,240对差异。此测试不是穷举全部2^32通道组合。

独立O4小核排除地址/常量装载等脚手架后，旧核心13条、A12条、B9条；A没有实现预期11条。SASS文本见baseline/exact/fast-pack.sass。全38活跃核统计含NOP等固定尾部，计数口径见audit.py：指令176431→174695(A)/164659(B)，HMMA均13188；LDL/STL 108/109→102/105(A)、104/109(B)。FB01最大STACK96→96(A)/104(B)，其他FB最大STACK不变。不能声称零spill。
