# DLSS5-AMD 0.42：更新内容与使用说明（历史归档）

> **⚠️ 最新通用版说明已迁移至固定入口：[使用与参数配置说明.md](使用与参数配置说明.md)**（涵盖 0.44 `0.5x` Small 模型、F9 四档循环、三层配置与全部参数配方）。

0.42 历史下载：[夸克](https://pan.quark.cn/s/316704620069) · [Gofile](https://gofile.io/d/HNE20Ocp)。提供三个完整包，按下表选择。

## 先选对包

| 包 | 用途 | 注意 |
|---|---|---|
| `OptiScaler-DLSS5-AMD-0.42.zip` | 常规游戏接入，例如《剑星》 | OptiScaler、ReShade和DLSS5插件配套使用；游戏能用OptiScaler，不代表一定已适配本插件 |
| `Magpie-DLSS5-AMD-0.42.zip` | 用窗口缩放器处理游戏，不要求游戏自带超分 | 独立解压使用，先用窗口／无边框；本指南的MODE1/2/3不适用于这个包 |
| `OptiScaler-REFramework-DLSS5-AMD-0.42.zip` | 《生化危机9》等已有专用说明的特殊接入 | 专用宿主和`LmxxfNrRuntime.dll`成对使用，不能与常规包混装，也不能推定所有RE引擎游戏通用 |

需要RDNA4显卡与带`amdhip64_7.dll`的AMD驱动。RX9070XT是真机验证平台；gfx1200模块随包提供，但没有本机硬件验证。**不需要另装HIP SDK、CUDA、预览版DXC或开发者模式。**

## 安装、升级：先备份，再整套更新

1. 完全退出游戏或Magpie。备份原安装目录中的同名DLL、add-on、`OptiScaler.ini`，以及整个`DLSS5-AMD`目录。已有ReShade／OptiScaler配置也一起备份。
2. 首次安装常规／专用包，按包内README放到实际游戏EXE旁，而不是启动器目录。《剑星》通常是`StellarBlade\SB\Binaries\Win64`。Magpie解压到独立目录，使用包内已经配好的程序和效果组。
3. **升级用同一种完整包更新，不要只换一个DLL，也不要把三种包混在一起。** 保留自己的`custom-config.txt`；不要盲目用新包覆盖已经调好的OptiScaler／ReShade设置，先对照包内说明合并。旧注入器与重复add-on应先备份移出，不能直接删除不认识的游戏DLL；已有`_storage_`副本时，也按该包说明一并核对。
4. 新包的`default-config.txt`可以更新。第一次自定义时，将`DLSS5-AMD\custom-config.template.txt`复制为`custom-config.txt`；已有custom文件就直接编辑，不用重新复制覆盖。
5. 初次测试先关插帧，保持MODE0／1x，确认网络正常工作后再调效果。卸载时恢复安装前备份，尤其是被替换的同名DLL。

常规包中，游戏菜单选择的是输入接口；最终超分后端由OptiScaler控制。可按Insert打开其面板。Magpie效果组中的`FSR3_SR`是本插件入口，后续FSR4负责放大；不用再额外添加一个“DLSS5滤镜”。Magpie默认`Alt+Shift+A`启停缩放。

## 设置到底写哪里？

通常只改 **`DLSS5-AMD\custom-config.txt`**，一行一个键，只写你要修改的项目。用记事本保存为UTF-8，留意不要变成`custom-config.txt.txt`。

优先级由低到高：

`default-config.txt → custom-config.txt → 旧native-game-flags.txt → 进程已有的DLSS5_*环境变量`

后面的同名键会盖过前面；同一文件重复写，以最后一行为准。旧`native-game-flags.txt`仍然生效，所以“custom改了没反应”时，先找旧native里的同名行，再查环境变量。不要同时在几处改同一项。

默认文件供查阅，**不要把自己的设置写进default**，否则下次升级容易丢。也不建议把整个default复制成custom，这会让旧默认永久覆盖新版本改进。下面的代码块是不同用法，选择需要的一个，不要全部叠加粘贴。

### 最小示例：保持默认单遍，稍微收一点效果

```ini
DLSS5_TEMPORAL_MODE=0
DLSS5_MULTI_PASS=1
DLSS5_STRENGTH=0.7,0.3
```

`STRENGTH`必须写两个数：前面控制亮度细节／光照转移，后面控制颜色混合。`1,1`是完整混合，`0.7,0.3`只是较温和的起点，不是统一最佳值。常规／Magpie接受每项0～3，RE9接受0～1；日常先在0～1内调整。

默认`DLSS5_STRENGTH=auto`：常规插件按游戏选择（例如《赛博朋克2077》默认`1,0`，其他通常`1,1`）；RE9沿用宿主菜单或runtime默认。需要恢复自动时，删掉custom里的这一行即可。强度`0,0`只抑制输出增强，**仍然计算网络**。

常规／Magpie的基础STRENGTH可热重载，通常约一秒生效；RE9改文件后重启。网络档位、时序模式等设置，最稳妥的操作都是退出后重启。

## 常用设置：先理解区别，再调

| 想做什么 | 设置／操作 | 说明 |
|---|---|---|
| 比较开关前后 | 常规／Magpie按F6 | 旁路网络；不要用基础强度0代替“停止计算” |
| 隐藏屏幕文字 | add-on按F7 | 只控制状态／FPS文字，不改变网络或画质；RE9显示由专用宿主控制 |
| 比较AE与EXACT | 常规包启用复用时按F8 | AE指ViT自适应复用；EXACT只是不使用该复用，不代表等于NVIDIA原版或关闭快速数值 |
| 调整遍数 | `DLSS5_MULTI_PASS=1/2/3` | 1x是一遍；2x是真跑两遍；默认3x是真跑两遍后预测第三遍，有损 |
| 要真实三遍 | `DLSS5_MULTI_PASS=3`和`DLSS5_MULTI_PASS_PREDICT=0` | 比默认预测3x更贵，不保证一定更适合你的画面 |
| 游戏内切遍数 | 常规／Magpie按F9 | MODE0时轮换1→2→3并保存custom；RE9改文件后重启 |
| 手动指定网络档 | `DLSS5_NETWORK_HEIGHT=900`等 | 支持`auto`、`720`、`900`、`1080`；这是网络计算档，不是显示分辨率 |

常规包默认`DLSS5_VIT_ADAPTIVE=1`，Magpie／RE9默认0。想关掉近似复用，在custom写`DLSS5_VIT_ADAPTIVE=0`并重启；不要把F8当作三包通用功能。多遍和时序会话可能自动禁用实际复用，AE标签也不能证明每一帧都跳过了计算。

档位默认`auto`：按实际网络输入两轴是否落在档位110%范围选720／900／1080。例如2K输出的质量档输入1707×961，通常选择900计算档；显示器设成2K，并不意味着网络必须跑1080档。先保持auto，想节省计算再试固定900；强制更小档位会牺牲输入细节。1080档默认`DLSS5_NETWORK_1080_ROWS=1152`，不建议新用户改1088。`DLSS5_NETWORK_FREE_RES=1`是按输入原尺寸计算的另一条选择，像素越多成本越高，日常先不动。

快速数值`DLSS5_FAST_NUMERIC=1`是发行默认。它与AE是两回事；EXACT状态下也可能使用快速数值。先保留默认，不要把内部HIP优化开关当作画质菜单逐项乱开。

## MODE0／1／2／3：不是“跑几遍”

**以下新时序消费者只用于常规HIP插件及配套RE9 runtime，不用于Magpie包。** 模式键是`DLSS5_TEMPORAL_MODE`，默认0；它与`DLSS5_MULTI_PASS`是两个不同选项。

| MODE | 做什么 | 适合怎样试 |
|---|---|---|
| `0` | 保持普通网络输出，不开这套时序处理 | 推荐先用它建立对照，日常默认 |
| `1` | TheAutomatic Fast History：模型门控上一帧输出，并反馈到下一帧输入 | 需要完整0.42资产；可能有拖影，并非原版NGX时序的精确复现 |
| `2` | 只让低频修正随时间更稳定，高频保留当前帧 | 想试低频闪动抑制时，可先与MODE0对比；不等于两遍增强 |
| `3` | 一次网络后增强低、高频残差，低频同时保留时域稳定 | 风格更强也可能更暗、反差更大或放大假纹理；不是“一次等于两次网络” |

模式1／2／3都要求 **`DLSS5_MULTI_PASS=1`、graph关闭、无overlap／外部history，也不能叠旧`DLSS5_TEMPORAL_HISTORY_EXPERIMENT`**。保留包内相关默认；升级前如果自己开过这些实验项，先去掉冲突设置。切模式需要重启，不能靠F9切MODE。时序模式开启时，F9会阻止切到2x／3x，手工写非法组合也会被拒绝。

试MODE2，最小custom内容：

```ini
DLSS5_MULTI_PASS=1
DLSS5_TEMPORAL_MODE=2
```

试MODE3，可从温和一点的额外强度开始：

```ini
DLSS5_MULTI_PASS=1
DLSS5_TEMPORAL_MODE=3
DLSS5_TEMPORAL_ENHANCE_STRENGTH=0.5
```

然后完全退出并重启游戏。想试模式1，把MODE改成1即可，但必须保留完整新包的history权重及匹配模块，不要只拿旧包改开关。

`DLSS5_TEMPORAL_ENHANCE_STRENGTH` **只控制MODE3额外增强**，默认1、有限范围0～2，改后重启；它不是上面的两项`DLSS5_STRENGTH`。值0会保留本帧普通单遍网络输出，1是该模式的默认额外增强，2更强；不建议直接从2开始。MODE3冷帧也会立即增强，不用等历史积累。

运动引导也有边界：常规插件只有在资源和运动／深度约定明确有效时才使用引导；未知时用静态屏幕坐标回落。RE9 runtime的接口没有已验证运动／深度引导，使用静态历史，不能当作已经做了运动补偿。快速转镜、遮挡或曝光变化时注意拖影；不喜欢就回MODE0并重启。

## 0.42更新了什么？

- 将0.41后已采纳的数据流与提交优化纳入正式三个包：减少部分复制／重复转换，900档范数复用与1440档的特定快速数值路径仍各自遵守已验范围。
- 提供上述可选MODE1／2／3、配套history资产与F9防误切，**默认仍为MODE0和1x**。
- 已验1152／RX9070XT范围内，ViT权重紧凑存储合计少216MiB持有容量（expand96＋contract96＋projection24）；无history会话另少33.75MiB共享buffer分配宽度。它们不是“峰值显存必少这么多”，也不保证所有显卡／档位都提FPS；不适用的布局会回落旧路。
- 模块与宿主配套打包，已停止的V末屏障、prefix NT等试验没有带入产品。完整改动见[0.42更新日志](https://github.com/lmxxf/dlss5-on-amd-9070xt-porting/blob/main/CHANGELOG.zh-CN.md)。

## 效果不合适／修改没生效怎么办？

先回到MODE0、1x；降低基础STRENGTH，或者用F6对比原效果。想恢复包默认，退出后备份并移走自己的custom文件，同时处理旧native中的覆盖项和系统环境变量，再重启。不要删除default、权重或HIP模块。

看不出变化时，确认文件名／所在目录、旧配置优先级和网络状态；F7隐藏文字不等于关闭效果。出现INIT／ERROR／UNSUPPORTED等状态时，先按对应包README排查，不要靠叠更多开关修复。反馈时带游戏名、显卡、驱动、所用包、自己的custom内容，以及`DLSS5-AMD\logs`；设置和画面取舍可以一起判断。

完整配置参考：[配置说明](https://github.com/lmxxf/dlss5-on-amd-9070xt-porting/blob/main/scripts/CONFIGURATION.zh-CN.md)。首次使用先保持默认，一次只改一个选项，在相同场景比较，比同时开一堆设置更容易判断。
